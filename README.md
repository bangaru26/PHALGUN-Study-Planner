# PHALGUN Study Planner

A free, mobile-friendly study desk for GFPA / PHALGUN learning.

## Open the app
After GitHub Pages deployment, the app is intended to be available at:
https://bangaru26.github.io/PHALGUN-Study-Planner/

## Included
- Accounting Fundamentals lessons with practice quizzes and score feedback
- Lesson notes saved in this browser
- Study timer and session history
- Daily/weekly study targets and timetable
- Progress overview and review of completed work
- CSV export and JSON backup/restore
- Installable web-app metadata and offline app-shell cache

## Privacy and limits
This standalone mini-module stores notes, quiz results and session history in this browser's local storage. It has no account login or cloud synchronization. Different browsers/devices do not automatically share progress. Use JSON backup/restore to transfer it. Do not enter passwords, government ID numbers, banking details or other sensitive information.

## Deploy
The `.github/workflows/pages.yml` workflow deploys this repository to GitHub Pages on pushes to `main`. In repository Settings → Pages, choose **GitHub Actions** as the build and deployment source if GitHub asks.
