3. Android, Windows & PWA compatibility

Android phone

  • Use an up-to-date Chrome/browser for Study Desk PWA.
  • Reading, notes and quiz work can be mobile-friendly.
  • Power BI Desktop, full desktop Excel/VBA, many database clients and SAP GUI are not phone-native labs; use alternatives or Lucky/another Windows PC.

Windows PC

  • Check each vendor's currently supported Windows release and 64-bit requirements.
  • Install tools from official publishers only.
  • Some apps need admin rights, account sign-in or cloud connection; plan accordingly.

PWA / offline

  • Installability and offline caching depend on browser/device.
  • Cloud tools and vendor portals require internet.
  • Export Study Desk data regularly; browser storage is not a substitute for backup.

5. Data safety and license check

  • Use fictional/synthetic finance data in exercises.
  • Never upload employer/customer records, personal data, bank details or confidential notes to public AI tools.
  • Verify license, free tier, quota and account requirements before use; “free to learn” does not mean unrestricted commercial use.
  • AI output can be wrong. Verify formulas, accounting treatment, standards, citations and code with trusted evidence and human review.
  • Use only authorized training environments; do not bypass organizational controls or vendor terms.
